## Context

0.1 provides `milestone` blocks (`threshold`/`reward_label`/`gift_product`) and `show_tracker`/`progress_message` settings. No milestone/rewards-ladder UI exists in the codebase today. 1.1 provides the shell region this renders into, above the line items.

## Goal

A milestone tracker that computes reached/not-reached per block against the cart's post-discount subtotal, renders the templated progress message, animates state transitions, and attaches/detaches a gift line via theme JS.

## Requirements

### Functional
- Outer container 374×124, radius 15, `#466E2E` @2 stroke; message strip, tracker row, connectors, badges, numbers row per TDD §5.3 measured boxes
- Reached: connector solid `#466E2E`, badge fill `#466E2E`@20%/stroke @1, checkmark icon; not-reached: connector `#FACC15`@40%, badge fill `#FACC15`@20%/stroke @1, padlock icon (as drawn)
- Progress basis = subtotal after discounts, recalculated on every cart update
- All milestones reached → all show reached, progress message suppressed
- Connector fill/width and badge fill/stroke transition smoothly on crossing (CSS transition, not a snap)
- A milestone with `gift_product` attaches it as a gift line via theme JS when reached, detaches it when the cart drops back below threshold

## Approach

New `snippets/cart-milestone-tracker.liquid` rendering `section.blocks` of type `milestone`; reached/not-reached computed in Liquid from `cart.total_price` minus discount allocations, re-evaluated by 4.1's re-render wiring on every mutation. Gift attach/detach is new JS in `assets/cart-drawer.js`, calling `/cart/add.js` when a threshold is crossed and `/cart/change.js` to remove it, gated on the milestone's `gift_product` setting. TDD D2 (reached-badge icon) has no asset yet — use a checkmark placeholder and flag it, don't block on it.

- TDD D4 (gift line pricing strategy — how the $0 price is shown, and what happens if the customer removes the gift) is unresolved in the source doc. Resolve and record it during this PRD's `/clarify`, don't silently invent a price override
