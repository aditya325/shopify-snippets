## Context

`snippets/cart-line-item.liquid` already exists and is rendered by `sections/cart-drawer.liquid` inside `[data-cart-items]`. `assets/cart-drawer.js` already implements the quantity stepper's trash↔minus swap (`_handleQtyChange`, `_handleQtyRemove`) and optimistic updates via `CartStore` — this is reused, not rewritten. The category-color metafield already exists from the homepage sprint (`docs/roadmap-homepage/`).

## Goal

Cart line items match TDD §5.4/§5.5 pixel-for-pixel in both standard and gift forms, using the existing stepper JS untouched.

## Requirements

### Functional
- Standard line: 350×72, 72×72 image (radius 12, `#E5E5E5` @0.5 stroke), category label colored per metafield, one-line truncated title, current price + struck-through original price, "20%Off" discount text, quantity stepper
- Gift line: 286×72 product-info width (no stepper-width squeeze), no price row at all, no title truncation, "Free" pill (`#FACC15` @20%, `#171717` text) occupying the stepper's slot
- Divider between lines: 350×1, `#DBD2C0`
- Quantity stepper: 64×24 controls, radius 6, `#E5E5E5` stroke — visual restyle only

### Non-Functional
- None beyond matching measured values

## Approach

Rework `snippets/cart-line-item.liquid` markup/Tailwind classes. Add a gift-line branch keyed off a line-item property (coordinate the exact property name with 2.3, which sets it when attaching the gift). Category color reads the same metafield pattern already used in `snippets/product-card.liquid`.

## Expected Output

- `snippets/cart-line-item.liquid` — restyled, gift-line branch added

### Downstream (unblocked by this phase)

## Constraints

- Do not rename `data-item-key`, `data-cart-line-qty`, `data-quantity-minus`, `data-quantity-plus`, `data-icon-delete`, `data-icon-minus` — `assets/cart-drawer.js` queries them directly

## Acceptance Criteria

- [ ] Standard line matches §5.4 measured boxes and truncates the title with an ellipsis
- [ ] Gift line renders no price row and shows the Free pill
- [ ] Existing stepper JS (trash↔minus swap, optimistic update, debounce) works unmodified
- [ ] Category label color matches the product's existing metafield value
