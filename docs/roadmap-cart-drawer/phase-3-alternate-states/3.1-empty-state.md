## Context

The current `[data-cart-empty]` block in `sections/cart-drawer.liquid` is a one-line message and a "Shop now" link — this phase replaces it entirely. `assets/cart-drawer.js`'s `_onStoreChange` (lines 377-387) already toggles `[data-cart-empty]`/`[data-cart-items]`/`[data-cart-footer]` visibility on cart-count changes — that swap logic is reused, not rewritten. 2.4 establishes the product-card partial and its "Buy"/"Add to Cart" label param this phase reuses.

## Goal

The empty-cart state matches TDD §5.12 — illustration, heading, message, and a 2-column "Popular Picks" product grid — with the checkout footer replaced by a "Start Shopping" CTA, swapped in and out without remounting the shell.

## Requirements

### Functional
- Hero: 140×140 illustration from `empty_illustration` (TDD D3 — flag as a required asset input; build the slot to degrade gracefully with none supplied), heading from `empty_heading`, message from `empty_message`
- Grid: 2 columns of products from `empty_products` (or `empty_collection` fallback per TDD §7.1), each card reusing 2.4's product-card partial with `add_to_cart_label: "Add to Cart"`, no wishlist heart
- Footer swaps to `empty_button_label` ("Start Shopping →") linking to `empty_button_link`, reusing the same 82-tall footer container from 1.1 rather than a new element

## Approach

Rework the existing `[data-cart-empty]` block in `sections/cart-drawer.liquid`. Call 2.4's recommended-products card partial with the "Add to Cart" label param rather than duplicating card markup.

## Expected Output

- `sections/cart-drawer.liquid` — `[data-cart-empty]` block rebuilt

## Constraints

- No wishlist control anywhere in the drawer (TDD §11)
- The shell must not remount when swapping in/out of this state — verify focus trap and scroll listeners survive the swap

## Acceptance Criteria

- [ ] Illustration slot renders `empty_illustration` when set, degrades gracefully (no broken image) when not
- [ ] Grid shows exactly 2 columns of products from `empty_products`/`empty_collection`
- [ ] Footer button reads "Start Shopping →" and links to `empty_button_link`
- [ ] Removing the last cart line swaps to this state without remounting the drawer shell
- [ ] No wishlist heart anywhere in the card
