## Context

`sections/cart-drawer.liquid` currently ships a minimal shell: overlay, panel, a plain header (title + count + close), a scrolling items region, and a basic footer — no offer banner, no milestone slot, no discount slot. `assets/cart-drawer.js` already implements open/close, Escape, backdrop click, focus trap, and section-morph re-rendering for `[data-cart-items]`/`[data-cart-footer]` — none of that is touched here. The site header's cart badge (`snippets/header-desktop.liquid:105`, `header-mobile.liquid`) already shows a live, wired-up count via `data-cart-count`; only its visual style changes.

## Goal

The drawer's shell — banner, header, four scroll-region height states, sticky footer — matches TDD §4.1/§4.2/§5.1/§5.2/§5.11 exactly, and the site header's cart badge matches the Cart Badge frame, with all existing JS behavior preserved untouched.

## Requirements

### Functional
- Offer banner: 390×28, padding 6/20/6/20, fill `#466E2E`, rotates 3 messages (Easy 7-Day Return / Express Delivery / Free Delivery Over ₹499) every `rotation_interval` seconds
- Header: 390×54, "My Cart" (Space Grotesk Medium 18, `#171717`) + count badge (24×24, DM Sans Regular 14, `#171717`, reads 0 when empty) + close button
- Scroll region is the only scrolling area, at 4 heights: 680 (default) / 642 (discount applied) / 680 (empty) / 456 (offers panel, padding 8/20/0/20)
- Sticky footer: 82 tall by default, 120 tall with the coupon row inserted (§5.8, built in 2.1)
- Site header cart badge: restyle to match the Cart Badge frame (`#F4C430` fill, `#171717` text) — visual only

### Non-Functional
- No inline `style`/`script` (Global Standards)

## Approach

Rework `sections/cart-drawer.liquid` markup and Tailwind classes; do **not** rename or remove any `data-cart-*` attribute that `assets/cart-drawer.js` queries (`data-cart-overlay`, `data-cart-panel`, `data-cart-items`, `data-cart-footer`, `data-cart-close`, `data-cart-checkout`, `data-cart-trigger`, `data-cart-header-count`). Scroll-region height is state-driven — toggle a data attribute or conditional class based on which shell state is active, not a hardcoded height. New `snippets/cart-offer-banner.liquid` renders the rotating messages; rotation is a small new script (extend `assets/cart-drawer.js` or a new tiny module) reading `rotation_interval`. Header badge restyle is a Tailwind class change only in `header-desktop.liquid`/`header-mobile.liquid`.
