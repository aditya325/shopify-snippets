# PRD: 3.2 — Popular Products Group

**Phase:** Phase 3 — Default State
**Priority:** P0
**Depends on:** 3.1 Chip Groups
**Estimated scope:** Small (1-3 files)

## Design Reference

- **Desktop:** https://www.figma.com/design/MpunnzguzvJ2SsXESNVVZ7/Development-For-INTENT?node-id=463-37505
- **Mobile:** https://www.figma.com/design/MpunnzguzvJ2SsXESNVVZ7/Development-For-INTENT?node-id=463-39655
- **Frames:** `Similar Products` group `463:37577` (desktop) / `463:39724` (mobile). Card spec in `.buildspace/artifacts/search/design-context.md` under "Desktop — product card".

## Context

After 3.1 (`docs/roadmap-search/phase-3-default-state/3.1-chip-groups.md`), both chip groups render and
`snippets/search-group-heading.liquid` exists to reuse. `popular_collection`, `popular_products_count`
and `popular_heading` exist from 1.1. `snippets/product-card.liquid` already renders the exact card the
design shows — badge, category eyebrow, highlight line, radiator rings, price row, Add to Cart — driven by
`custom.*` product metafields, with a `hide_add_to_cart` parameter. The current modal renders its own
inline mini-card instead, which this PRD replaces.

## Goal

The Popular Products group rendering the shared `product-card` at design fidelity — four across on
desktop, two columns on mobile — sourced from the merchant's chosen collection.

## Requirements

### Functional
- Group heading reuses `snippets/search-group-heading.liquid` with a 20×20 box icon and `popular_heading`
- Products come from `settings.popular_collection`, limited by `settings.popular_products_count`
- Cards render via `{% render 'product-card' %}` with Add to Cart **shown** (Sprint §1)
- Desktop: one row, `flex` with 20px gap, each card `flex-1` — deriving 265px at four cards in 1120
- Mobile: two columns, 10px gap between columns and between rows, each column `flex-1` — deriving 170px in 350
- Delete the inline mini-card markup currently in `snippets/search-modal.liquid`
- The group does not render when the collection is unset or empty
- Card images lazy-load — this group is inside a modal, never above the fold

### Non-Functional
- Adding or removing products must not change any card's declared width — the layout derives it

## Approach

Replace the inline product markup in the default-content container with a `product-card` render loop.
The card is already built and already carries the three load-bearing utilities documented in its `{% doc %}`
block (`tracking-normal` on the root, `flex-wrap` plus `whitespace-nowrap` on the price row) — do not
re-implement or override them. Width comes from `flex-1` with the gap set, per CLAUDE.md: at four cards in
1120 with a 20px gap this computes to exactly 265px, matching Figma, and stays correct if the merchant
sets the count to 3 or 5. Mobile is two `Product Column` wrappers each `flex-1`, matching the design's
structure rather than a `grid-cols-2`, so a card and its column stay one unit. Pass `card_class` only if a
search-specific override is genuinely needed, and pair both breakpoints if so — an unprefixed utility in
`card_class` overrides the snippet's own `lg:` utilities at every width.

## Expected Output

- `snippets/search-modal.liquid` — Popular Products group rendering `product-card`; inline mini-card removed
- One 20×20 box icon snippet for the group heading

## Dependencies

### Upstream (must be done first)
- 3.1 — provides `snippets/search-group-heading.liquid`, and edits the same container
- 1.1 — provides the three Popular Products settings

### Downstream (unblocked by this phase)
- 4.1 product-results-grid — reuses this group's card grid geometry for the typed state

## Constraints

- `product-card` is driven by `custom.*` metafields; products lacking them render with empty badge, category and highlight regions. This is a content-readiness issue, not a code defect — flag it if the chosen collection has unpopulated products
- No declared card width (CLAUDE.md); `w-[265px]` and `w-[170px]` are both forbidden
- `popular_products_count` is bounded 1–12 by its schema (D-6); the design shows 4 and the default is 4
- Card content is not restyled in this PRD — `product-card` ships unchanged and is shared with eight other call sites

## Acceptance Criteria

- [ ] Desktop renders four cards in one row at exactly 265px each, derived from `flex-1` and a 20px gap — no declared width in the markup
- [ ] Setting `popular_products_count` to 3 renders three cards that redistribute to fill 1120, with no layout break
- [ ] Setting it to 12 does not overflow the panel horizontally
- [ ] Mobile renders two columns at 170px in a 350px container with a 10px gap
- [ ] Cards show Add to Cart, and it opens the cart drawer with the modal still open behind it
- [ ] With `popular_collection` unset, the group does not render — not an empty heading
- [ ] All card images carry `loading="lazy"`
- [ ] `snippets/product-card.liquid` is byte-identical to its state before this PRD
- [ ] The other eight `product-card` call sites render byte-identically to before this PRD
- [ ] Desktop matches `figma-search-desktop.png` and mobile matches `figma-search-mobile.png` for this group
