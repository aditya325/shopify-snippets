## Context

`sections/product.liquid` exists today — 225 lines of themex base with blocks
`title`, `price`, `variant_selector`, `buy_buttons`, `description`, `collapsible` — and
`templates/product.json` wires it as `"main"`. By decision this PRD **rewrites that file in place**
rather than adding a parallel `main-product.liquid`, so the filename and `type: "product"` reference
stay valid. This PRD delivers the section shell, the responsive two-column grid and the gallery only;
1.2 fills the buy box. Embla is already vendored (`assets/embla-carousel.umd.js`, loaded deferred and
global from `snippets/core-assets.liquid:18`) — there is **no shared initialiser module**, so this
section writes its own JS like the seven existing carousel scripts do.

## Goal

A rewritten `sections/product.liquid` rendering the PDP's two-column desktop row and stacked mobile
layout, with a fully working product gallery on both breakpoints and an empty, correctly-sized buy-box
column awaiting 1.2.

## Requirements

### Functional
- Desktop: one row, media column 720 and buy-box column 720 inside the 1440 frame. Gallery padding
  10/0/24/20 with a 10 gap; thumbs rail 73 wide, main image 617×640, both derived from the layout.
- Mobile: gallery and buy box are two stacked siblings. Gallery is 390×378, padding 10/20/0/20, gap 10.
- Desktop gallery: vertical thumbs rail alongside the main image; clicking a thumb drives the active
  slide. `thumbnail_count_desktop` (range) sets how many thumbs show before the rail scrolls.
- Mobile gallery: main image is a swipeable Embla carousel; thumbs are a **second** Embla carousel
  beneath it (48×48, gap 4). Thumb-carousel arrows render only when thumb count exceeds what fits, and
  the prev/next arrow is disabled at each respective end.
- The two mobile carousels stay in sync in both directions — swiping the main image moves the thumb
  selection and vice versa.
- Bestseller badge: desktop `544:24352` 89×32 radius 6 on `#f4c430`; mobile `544:32523` 64×26 radius 4.
- Share control behind `enable_share`, using the Web Share API with a copy-link fallback.
- Wishlist control behind `enable_wishlist`, rendered as a non-functional placeholder (D2, Flits not
  integrated). Reuse `snippets/icon-wishlist.liquid`.
- Section settings created here: `enable_share`, `enable_wishlist`, `thumbnail_count_desktop`.
  `delivery_min_days`, `delivery_max_days` and `free_gift_message` are added by 1.2.

### Non-Functional
- Main gallery image is the above-the-fold hero: it must **not** carry `loading="lazy"`.
- Thumbs and non-first slides lazy-load.
- Gallery is keyboard operable and thumbs expose active state via `aria-current`, matching the
  pattern in `assets/media-carousel.js`.

## Approach

Rewrite `sections/product.liquid` keeping its filename and schema `type`. Structure the root as a
wrapper carrying vertical margin per the project spacing rule (margin, never `py-*`), with
`.page-width` on an inner element. Desktop's two columns are a `lg:` grid whose widths derive from the
layout — no static `w-[720px]`. Render media through `snippets/image.liquid` for the `<picture>`/WebP
srcset. Write `assets/product-gallery.js` as a `DOMContentLoaded` script reading `data-*` attributes,
following `assets/media-carousel.js` — guard on `window.EmblaCarousel` and return early if absent.
Desktop needs one Embla instance plus a thumbs rail; mobile needs two instances wired bidirectionally
via each other's `scrollTo` and `on('select')`. Use one markup tree with responsive behaviour rather
than duplicate desktop/mobile markup, so there is a single source of alt text and media order. Drive
the thumb-arrow disabled state off Embla's `canScrollPrev`/`canScrollNext`, not off an index count.
The nested yellow concentric rings behind the main image (`544:24328`, six `#eab308` rings at
descending stroke widths, group opacity 0.3) are decoration — render them as CSS or an inline SVG, not
as six DOM rectangles, and mark them `aria-hidden`.

## Expected Output

- `sections/product.liquid` — rewritten: shell, responsive grid, gallery, 3 section settings
- `assets/product-gallery.js` — desktop thumbs+main and mobile dual-carousel logic
- `templates/product.json` — `blocks` reduced to what 1.1 renders; 1.2 restores the full block order
- `assets/product-gallery.css` — only if the rings or thumb rail need non-Tailwind CSS

## Dependencies

### Upstream (must be done first)
- None. Gallery reads native `product.media`, not metafields, so it does not wait on 0.1.

### Downstream (unblocked by this phase)
- 1.2 main-product-buy-box — needs the section shell and the buy-box column to exist
- 1.12 sticky-atc — observes the primary Add to Cart button, which 1.2 adds inside this shell

## Constraints

- Rewriting `product.liquid` in place removes the themex `collapsible` block. Confirm nothing else
  references it before deleting, and record the removal as a deviation if anything does.
- No shared Embla initialiser exists — do not invent one here. Seven asset files already use the
  per-section pattern; match it.
- An unprefixed `px-*` overrides `.page-width` at **every** width, not just mobile. Pair both
  breakpoints.
- Layout widths are derived, never declared. The 720/720 split comes from the grid, not `w-*`.
- Vertical spacing is margin on the wrapper. This section paints no background, so padding stays 0.
- Comments are one line or none.
