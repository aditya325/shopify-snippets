## Context

This is a standalone four-item claim strip with no data dependency — content comes from repeatable
section blocks, so it can be built at any point in Phase 1. The Figma frames carry **different copy on
each breakpoint**, which was raised as TDD OD1. That decision is now closed: **the desktop set is
canonical on both breakpoints** (devx, this sprint). The mobile labels are not built.

## Requirements

### Functional
- Desktop 1440×162, padding 32/0/32/0, no side padding, background `#ffffff`. Four items in an equal
  row, each a column with a 56×56 icon over a centred label, 12 gap.
- Mobile 390×120, padding 24/0/24/0, no side padding. Four items, 34×34 icons, 8 gap.
- Labels use **Space Grotesk 500** — desktop 20/30, mobile 12/15, both title-case and centred, `#171717`.
  Icons are `#466e2e`.
- Repeatable `item` blocks with `icon` (`image_picker`) and `label` (`text`) — not four fixed slots, so
  the count can change without code.
- **Canonical labels, both breakpoints:** ISO Certified, GMP Compliant, AYUSH Approved,
  Dermatologically Tested. These are the block defaults.
- Mobile labels wrap to two lines in the design (e.g. "ISO / Certified"). Allow wrapping; do not force
  a single line or hard-code a break.

### Non-Functional
- Icons are decorative alongside a visible text label — mark them `aria-hidden` rather than duplicating
  the label in `alt`.
- Item widths derive from the row, so three or five blocks lay out correctly without code change.

## Approach

Create `sections/trust-strip.liquid`. Vertical spacing is margin on the outer wrapper; the section
paints `#ffffff`, so the painted element also takes the 32/24 vertical padding for its interior. There
is no side padding at either breakpoint, so omit `.page-width` on the row and let the four items divide
the full frame width — `flex` with `flex-1` on each item derives the 360 desktop and 97.5 mobile widths
exactly, and stays correct at other block counts. Icons come from `image_picker` blocks rather than the
theme's `icon-*` snippets, because these are brand certification marks the merchant supplies, not UI
glyphs. Space Grotesk is one of five families the design uses against the theme's two font variables —
resolve it through whichever variable the typography pass assigns rather than declaring a raw
`font-family`, and if no variable maps to it, flag that in the status log rather than hard-coding a
webfont.

## Constraints

- **OD1 is closed by decision in favour of the desktop set.** GMP Compliant and Dermatologically Tested
  are substantiable regulatory claims and ship as drawn on devx's instruction. This is recorded as a
  deviation from the mobile frame, which loses two of its four labels. Do not render both sets and
  hide one by CSS — that would place unsubstantiated claims in the DOM at every viewport.
- No side padding at either breakpoint, so `.page-width` does not belong on the item row.
- Layout widths derived, never declared — `flex-1`, not `w-[360px]`.
- Comments are one line or none.
