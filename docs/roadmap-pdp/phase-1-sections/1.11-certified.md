## Context

A row of certification marks, the simplest section in the sprint — five images and an eyebrow heading,
no data dependency and no JavaScript. D5 (certification marks and their alt text to be supplied) is
partly resolved already: the `/figma` extraction downloaded the section's six image fills — five of them
the visible logos — and uploaded them to Shopify Files with `shopify://shop_images/` references recorded
in the assets manifest. What
remains open under D5 is the **alt text**, which the design does not carry, and confirmation that the
Figma logos are the approved production artwork rather than placeholders.

## Goal

A `certified` section rendering a row of certification marks from repeatable blocks, with the five
design logos wired from Shopify Files.

## Requirements

### Functional
- Desktop 1440×196, padding 32/60/44/60 with a 24 gap. Note the **asymmetric vertical padding** — 32
  top, 44 bottom.
- Mobile 390×134, padding 24/20/32/20 with a 30 gap, centre-aligned.
- Eyebrow heading "Certified, Tested & Trusted" — DM Sans 600, 16/26 with 1px tracking, uppercase,
  `#737373` on desktop; 12/18 on mobile.
- Repeatable `logo` blocks with `image` (`image_picker`) and `alt_label` (`text`).
- Logo row is `space-between` with a 28 gap. Logos are intrinsically sized, not layout — the design's
  measured widths vary per logo (143, 142, 69, 69, 77 at 70 high on desktop; 61, 61, 29, 29, 33 at 30
  high on mobile), so height is fixed and width follows the aspect ratio.
- Five block defaults referencing `certified-section-image-1`, `-3`, `-4`, `-5`, `-6` from the manifest —
  **not** `-image-2`, which is the invisible stacked fill.

### Non-Functional
- Each logo's `alt` comes from `alt_label`. An empty `alt_label` renders `alt=""` (decorative) rather
  than falling back to a filename.
- Images lazy-load; this section is near the page bottom.

## Approach

Create `sections/certified.liquid`. Vertical spacing is margin on the outer wrapper; the section paints
no background, so padding stays 0 and the asymmetric 32/44 is expressed as margin — `mt-8 mb-11` on
desktop against `mt-6 mb-8` on mobile. That asymmetry carries none of the horizontal `px-*` hazard,
because `.page-width` sets no vertical padding. Put `.page-width` on an inner element for the 60/20
side padding. Logos are the one case where declaring a dimension is correct — they are intrinsically
sized content, not layout — so set a fixed height (`h-[70px] lg:h-[70px]`, `h-[30px]` mobile) and let
width follow via `w-auto`, which reproduces the five different measured widths without hard-coding any
of them. Use `snippets/image.liquid` for the responsive `<picture>`. Wire the block defaults to the
`shopify://shop_images/` references in `.buildspace/artifacts/pdp/assets-manifest.json` rather than
re-uploading, skipping `-image-2` per the warning above. Because the design gives no alt text, leave
`alt_label` defaults empty and record D5's remaining alt-text question in the status log rather than
inventing copy for regulatory marks.
