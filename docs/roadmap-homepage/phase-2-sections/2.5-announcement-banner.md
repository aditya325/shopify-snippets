## Context

Sprint §4.11. A thin offer strip — the smallest section on the page, and the **first carousel
section built**. That makes it a deliberate early proving ground: it establishes the standalone
carousel file shape the other four copy, on a one-line strip rather than inside the hero.

The Sprint is explicit that this is a **slide-by-slide auto-advancing carousel, not a marquee** —
a decision already taken. Advance interval comes from a section-level range setting.

Extraction: desktop is a single centred line, DM Sans SemiBold 16 uppercase at 1px
letter-spacing on `#466E2E`, 2px vertical / 72px side padding, 50px tall. Mobile is 12px type,
6px vertical / 10px side padding, 30px tall.

Note the theme already has `sections/announcement-bar.liquid` from themex — a different file
with a different name. Check whether it is in use before adding a similarly-named section.

## Goal

A thin, full-width auto-advancing offer strip driven by its own standalone carousel file, with merchant
control over colours, text blocks and advance speed.

## Requirements

### Functional
- Section-level: background colour (`color`), text colour (`color`), speed (`range`, the auto-advance interval)
- Block type `announcement` with: text (`richtext`), link (`url`, optional)
- Slide-by-slide advance via Embla — **not** a marquee, not a CSS animation
- Single block renders statically with no carousel initialised
- Measured padding: desktop 2 vertical / 72 sides; mobile 6 vertical / 10 sides

> **This section paints a background, so it takes BOTH:** `margin` on the wrapper for its separation from neighbours, and `padding` on the element carrying the background for the painted interior. Margin falls outside the painted box, so without the padding the band collapses to the content height (CLAUDE.md §5).
- Type: DM Sans SemiBold 16 desktop / 12 mobile, uppercase, 1px letter-spacing
- `presets`; no `max_blocks`

### Non-Functional
- Auto-advance pauses on hover and on focus, and respects `prefers-reduced-motion`
- No layout shift as slides change — all slides occupy the same height

## Approach

Write `assets/announcement-banner.js` against the `EmblaCarousel` and `EmblaCarouselAutoplay`
globals vendored by 0.6. Pass the merchant's speed setting as the autoplay `delay`, with
`stopOnMouseEnter: true`, `stopOnFocusIn: true` and `stopOnInteraction: false` — the plugin
defaults for the last two are wrong for this use. One slide per view, no dots, loop on.

This is the first carousel section built, so its file becomes the shape the other four follow.
Boot on `DOMContentLoaded`, matching the root by class selector.

Guard the carousel: with a single block there is nothing to advance, so emit the strip without
carousel data attributes at all rather than initialising a one-slide Embla instance.

`prefers-reduced-motion` matters more here than elsewhere — an auto-advancing strip at the top
of the page is exactly the pattern that motion-sensitive users need stopped. Honour it by
disabling autoplay, leaving the strip on its first slide.

Confirm the relationship with the existing `sections/announcement-bar.liquid` before naming this
file. If the themex bar is unused, note it for removal in 5.1; do not delete it here.

## Expected Output

- `sections/announcement-banner.liquid` — section with `{% schema %}`, `announcement` block type and `presets`
- `assets/announcement-banner.js` — standalone: no conditional activation, autoplay plugin with the merchant interval, loop on, no dots
- `assets/base.css` — strip styles only if utilities are insufficient

## Constraints

- Slide-by-slide carousel, explicitly not a marquee (Sprint §4.11)
- Owns a complete standalone JS file using the Embla globals vendored by 0.6. No shared module, base class or helper — duplication across the five carousel sections is accepted by decision. Boots on `DOMContentLoaded`
- Measured 72px desktop side padding is an intentional exception to the 60px standard

## Acceptance Criteria

- [ ] Multiple blocks advance slide-by-slide at the merchant's speed setting
- [ ] A single block renders statically with no Embla instance created
- [ ] Autoplay pauses on hover and on keyboard focus
- [ ] `prefers-reduced-motion: reduce` disables autoplay
- [ ] Background and text colours are merchant-controlled
- [ ] Type renders DM Sans SemiBold 16/12 uppercase at 1px letter-spacing
- [ ] Measured padding correct: 2/72 desktop, 6/10 mobile
- [ ] Optional link works; a block without one renders as plain text
- [ ] No height shift between slides
