## Context

Sprint §4.9. Lifestyle cards sitting on a configurable gradient wash behind the whole section.
Cards are fully clickable and carry a title, subline and image with a dark gradient overlay.

The extraction shows five `Concerns` cards at 160px wide on mobile inside a 350px viewport —
meaning the mobile row **overflows horizontally and scrolls**. Sprint §4.9 does not mention a
carousel for this section, and it is not in the Global Standards §6.4 carousel list, so this is
a plain horizontal scroll container rather than an Embla instance.

Card text is DM Sans SemiBold 20 desktop / 16 mobile at letter-spacing **-1px** — an unusual
value that is measured, not a typo.

## Goal

A blocks-based lifestyle card row on a merchant-configurable gradient wash, horizontally
scrollable on mobile, with fully clickable cards.

## Requirements

### Functional
- Section-level richtext heading (underline-enabled) and background gradient (`color_background`)
- Block type `lifestyle` with: image (`image_picker`), video (`video`), card title (richtext), subline (richtext), link (`url`)
- Video takes priority over image; poster from `video.preview_image`
- Whole card clickable; arrow from 1.1
- Mobile: horizontal scroll container with the cards' measured 160px width — **not** an Embla carousel
- Measured padding: desktop 32 vertical / 60 sides, gap 24; mobile 24 top / 20 sides, gap 24

> **This section paints a background, so it takes BOTH:** `margin` on the wrapper for its separation from neighbours, and `padding` on the element carrying the background for the painted interior. Margin falls outside the painted box, so without the padding the band collapses to the content height (CLAUDE.md §5).
- Card title letter-spacing -1px as measured
- `presets` with five default blocks; no `max_blocks`

### Non-Functional
- Horizontal scroll uses `scroll-snap` and hides the scrollbar without disabling keyboard scrolling
- Gradient overlay on card images is a CSS layer, not a second image

## Approach

Standard section skeleton with a block loop. The section gradient comes from a
`color_background` setting applied as an inline style on the section wrapper — Tailwind cannot
generate classes for arbitrary merchant gradients.

For the mobile overflow row, use a flex container with `overflow-x: auto`,
`scroll-snap-type: x mandatory` and `scroll-snap-align: start` on the cards. Do **not** reach
for Embla here — this section is absent from the Sprint's carousel list and from Global
Standards §6.4, and adding a JS carousel where the design shows native scroll would be scope
creep. Keep the scrollbar hidden via `scrollbar-width: none` and the `::-webkit-scrollbar`
pseudo-element, but leave keyboard and trackpad scrolling intact.

Card images carry a dark gradient wash (`linear-gradient(#17171700 0%, #171717B2 100%)` per the
extraction) so the white title and subline stay legible. Apply it as an overlay element or
`::after`, not as a `background-image` on the `<img>`.

Take the exact card dimensions, radii and gradient stops from the "Shop By Lifestyle" tables in
`design-context.md`.

## Constraints

- Not an Embla carousel — native horizontal scroll (absent from Global Standards §6.4)
- No CSS background images for content; gradient overlay layers are permitted
- Merchant gradient applied inline, not as a generated Tailwind class
- Letter-spacing -1px on card titles is measured — do not normalise
- No nested anchors

## Acceptance Criteria

- [ ] Desktop row matches Figma at 1440 with measured padding and 24px gap
- [ ] Mobile row scrolls horizontally with snap, cards at the measured 160px
- [ ] Scrollbar is hidden but keyboard and trackpad scrolling still work
- [ ] Section gradient wash is merchant-configurable and renders behind all cards
- [ ] Card gradient overlay matches the measured stops; title and subline stay legible
- [ ] Whole card clickable with no nested anchors
- [ ] Video beats image when both set
- [ ] Card title renders at DM Sans SemiBold 20/16 with -1px letter-spacing
- [ ] Adding or removing blocks does not break either layout
- [ ] Section addable from the theme editor with five default blocks
