## Goal

Seven 18px SVG icons exist, are selectable by the `rail_icon` setting, and render correctly in the
Shop By Need rail on both viewports.

## Requirements

### Functional
- Export 7 icons from Figma as SVG: Body Pain, Period Care, Rehydration, Cold & Congestion, Recovery, Grooming, Shop All
- Icons render at 18px square in the desktop rail and the mobile drawer accordion
- Upload to Shopify Files and confirm they are selectable in an `image_picker`
- A rail row with **no** icon set renders the label with no gap and no broken-image glyph

### Non-Functional
- Each SVG optimised — no Figma metadata, no embedded fonts — and under 4KB

## Approach

**Run the selectability spike first.** Shopify's documented theme image formats are JPEG,
Progressive JPEG, PNG, GIF, HEIC and WebP; SVG is not among them, and an SVG cannot pass through
`image_url` transforms. Before exporting all seven, upload one SVG to Files and confirm it appears
in an `image_picker` in the live theme editor. Five minutes, and it determines the rest of the PRD.

**The output path bypasses `image.liquid`.** Because `image_url` cannot transform an SVG, the rail
renders a plain `<img src="…" width="18" height="18">`. Do **not** route it through
`snippets/image.liquid`, which builds a `<picture>` with WebP srcsets and will produce broken output.

**Defined fallback.** If the spike shows SVGs are not selectable, ship the same 7 files as theme
assets rendered via `asset_url`, keeping `rail_icon` as an optional override. The schema shape does
not change either way, so 2.2 is unaffected.

One property is lost by design: an `<img>` cannot inherit `currentColor`, so each icon is baked at
the green it carries from Figma. The design needs no icon state change between active and inactive
rows, so this costs nothing — but a future colour change is a re-export, not a CSS edit.

## Expected Output

- Spike result appended to **D-12** in `docs/roadmap-navigation/deviations.md`
- Icon naming convention recorded in `status-log.md` so merchants can match icon to rail row
