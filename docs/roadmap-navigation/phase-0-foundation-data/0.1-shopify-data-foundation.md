## Goal

Every piece of Shopify-side data the header reads from exists, is populated, and has its handles
recorded — so no downstream PRD is blocked or building against placeholders.

## Requirements

### A. Metafield definitions (D1)
- `custom.publisher` on **Article** — `single_line_text_field`, the outlet name
- `custom.bundle_contents` on **Product** — `list.single_line_text_field`, one entry per bundle item
- Both storefront-visible, or Liquid cannot read them
- **No** metafield for the savings badge — Sprint §3.4 derives it from price
- Namespace stays `custom`, matching the six definitions already live from the homepage sprint

### B. Collections (D3) — 19 total
- **Shop By Need (7):** Body Pain, Period Care, Rehydration, Cold & Congestion, Recovery, Grooming, Shop All — ≥6 products each
- **Categories (6):** Pain Relief, Women's Care, Cold & Congestion, Rehydration, Grooming, Shop All — ≥5 products each
- **Combo (6):** Desk Recovery Kit, Women's Comfort Kit, Family Wellness Kit, Travel Essential Kit, Summer Hydration Kit, Workout Recovery Kit — ≥3 bundle products each
- ≥3 Combo products carry `compare_at_price > price`, or the derived savings badge can never be seen
- Products carry the homepage metafields (`product_badge`, `category_label`, `highlight_text`, `highlight_color`, `card_image`) so `product-card` renders complete

### C. Blogs (D2)
- **Blogs** blog, ≥3 published articles, each with a featured image, category badge and `custom.read_time`
- **News & Events** blog, ≥3 published articles, each with a featured image and `custom.publisher`
- Two separate blogs, not one blog with tags — the schema takes `blog` settings
- Published dates real and distinct; Sprint §5.5 derives the displayed date from `published_at`

### D. Navigation menu (D4)
- Top level: **Shop By Need · Categories · Combo · Offers · About · Media · Track Order** — ⚠️ the last two swap between frames, see decision 4
- Children: Shop By Need 7 · Categories 6 · Combo 6 · About 2 (Our Story, History) · Media 2 (Blogs, News & Events)
- **Offers and Track Order have zero children** — Sprint §3 requires them to render without a chevron
- Every child link points at its collection, page or blog
- Handle set on the header section

## Approach

Work in the order A → B → C → D; C needs A's metafield, D needs B's collections for link
destinations. Use the Shopify admin UI or the Admin GraphQL API with `SHOPIFY_STORE` and
`SHOPIFY_ADMIN_TOKEN` from `.env` — the dev app may need `write_metafield_definitions` added first.

**`bundle_contents` must be a `list.` type.** Liquid iterates `.value` as an array, which is what the
featured bundle card's tick-list renders. A multi-line text field would force string-splitting and
is the wrong choice.

Create collections as **smart collections** wherever a tag or product type can drive membership, so
panels stay correct as the catalogue grows.

**Four decisions must be made here, not deferred.** Record each in `status-log.md`; decisions 2, 3
and 4 are departures from the design and also need an entry in `deviations.md`:

1. **Overlapping collections.** "Cold & Congestion", "Rehydration", "Grooming" and "Shop All" appear
   in both the Shop By Need and Categories rails. Share one collection or duplicate per rail?
   Sharing is recommended — two entry points to the same catalogue slice.
2. **Top-level labels.** Desktop reads `Combo` and `Media`; the mobile drawer (`389:28380`) reads
   `Bundles` and `Blogs`, in a different order. One menu drives both. Recommend the desktop labels,
   since the panel headings use them.
3. **Categories rail labels.** Mobile reads Pain Relief, Women's Care, Hydration, Cold & Congestion,
   Recovery, Everyday Wellness against desktop's six. Pick one set.
4. **Top-level order — the design contradicts itself.** The five panel frames render
   `… About · Media · Track Order`; the scrolled frame `389:29163` renders
   `… About · Track Order · Media`. Both are desktop, so this is not a viewport difference. One
   order must win. Recommend the **panel frames'** order, since five frames agree against one, and
   the scrolled frame is already known to be stale (it also omits the chevrons, per Sprint §4.3).
