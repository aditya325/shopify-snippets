## Context

The first **split pane**: the pane narrows to 684px and a 352px Subscribe & Save promo sits beside it
at `x:1028`. Sprint §6 lists two new components for this panel — the **featured bundle card** and the
**popular bundle row** — and both are consumed only here, so they are built in this PRD rather than
separately.

Panel height measures 605px. Rail is 6 bundle kits with no icons.

> ⛔ **The TDD is frozen.** Never edit `docs/tdds/amrutanjan-navigation-sprint.md`.

## Goal

The Combo pane renders a featured bundle beside a stacked list of popular bundles, with the
Subscribe & Save promo in the right rail, on both viewports.

## Requirements

### Cards
- **Featured card:** image on top, `#faf9f6` body below; title in `#1E5631`, savings chip beside it, tick-list of contents, CTA button
- Savings chip: yellow, "SAVE N%", **derived** from `compare_at_price` vs `price` — **absent from the DOM** when there is no saving
- Contents list: one tick row per `custom.bundle_contents` entry, green check, `#666666` label. Single column desktop, two columns mobile
- **Popular bundle row:** product name, "From ₹N" in `#1E5631`, underlined "View Details" linking to the product
- Both take a `product` object; nothing passed as a literal string
- A product with no `bundle_contents` renders the card without the list, not with an empty one

### Panel
- Rail: 6 rows, no icons — Desk Recovery Kit, Women's Comfort Kit, Family Wellness Kit, Travel Essential Kit, Summer Hydration Kit, Workout Recovery Kit
- Pane heading "Combo of the month"
- Featured card from `featured_product`; three rows from `bundle_collection`, `bundles_count` default 3
- See All spanning the 684px pane, falling back to the bundle collection URL
- Right rail: `subscribe-save` with `layout: 'card'` when `show_subscribe_promo` is on
- With the promo off, the pane expands to the full 1068px rather than leaving a gap
- Mobile: page title "Combo", first accordion row "Everyday Bundles"; featured card stacks above a **2-up** row of the compact bundle cards; tick-list becomes two columns

## Approach

**Reuse the discount arithmetic already in `snippets/product-card.liquid`** rather than re-deriving
it. Sprint §3.4 is explicit that the badge shares that calculation so it cannot drift from the real
price. Read the existing implementation and lift the same expression.

`custom.bundle_contents` is a `list.single_line_text_field`, so `.value` iterates directly as an
array. Do not split a string — if iteration fails, the definition was created with the wrong type in
0.1 and that must be fixed there.

Tokens from Sprint §2.2: `combo-accent #1E5631` for bundle prices, View Details links and the
featured card's border; `muted-text #666666` for the contents list and any struck price;
`decor-shape #D9D9D9` for the shape peeking behind the bundle image. Build that shape as a sibling,
not a background on the image element, so the image can be swapped without losing it.

Money formatting is a real layout risk — this store renders "Rs. 1,499"-style strings, and "From
Rs. 1,499" plus a link is long for a compact row. Apply the `flex-wrap` + `whitespace-nowrap`
pairing that `product-card` documents in its own doc block, or a single price splits into "Rs." /
"1,499".

Derive pane width from `show_subscribe_promo` (2.2) — do not declare `w-[684px]`.

The mobile layout is a distinct arrangement, not a reflow. Build it explicitly.

Note for 4.3: the desktop rail heading reads "Everyday Combo" while mobile reads "Everyday Bundles".
One `pane_heading` serves both — take the desktop string, consistent with 0.1's label decision.

## Constraints

- Savings badge is **derived**, never a metafield and never merchant-entered (Sprint §3.4)
- Badge hides when there is no saving — do not render "SAVE 0%"
- `bundle_contents` is a list type; iterate it, do not split a string
- Reuse `product-card`'s discount arithmetic; do not write a second version
- Pane is 684px with the promo on, 1068px with it off — derived by 2.2, not declared here
- `bundle_cta_label` comes from the setting; no hardcoded "View Details"
