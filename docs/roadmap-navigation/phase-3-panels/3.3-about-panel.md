# PRD: 3.3 — About Panel

**Phase:** Phase 3 — Panels
**Priority:** P1
**Depends on:** 1.2 subscribe-save snippet, 2.2 mega-menu shell
**Estimated scope:** Medium (1 pane snippet + 1 card snippet)

## Design Reference

- **Desktop:** Our Story `389:23607`, History `389:24807`
- **Mobile:** Our Story `389:30722`. **History has no mobile frame** — desktop only in the design
- **Extraction:** `.buildspace/artifacts/navigation/` — already complete

## Context

Two rail rows, both split panes with the Subscribe & Save promo beside them. Our Story renders manual
content cards; History renders a single timeline thumbnail.

**The history carousel is cancelled — D-7 in `deviations.md`.** Sprint §5.4 and §6 specify an Embla
carousel with peeking slides and a repeating `history_slide` block, and §7 lists D7 for carousel
imagery. Approved scope is **one thumbnail**, which the desktop frame supports: `389:24807` shows a
single image, one caption and one CTA, with no arrows or dots. The faint shapes either side are
`decor-shape #D9D9D9`. So there is no carousel, no `history_slide` block, and no Embla dependency —
History is `history_image` + `history_caption` + `history_year` on `rail_item`, per 2.2.

This also removes any reason to look for a shared Embla init module, which does not exist — **D-9**.

> ⛔ **The TDD is frozen.** Never edit `docs/tdds/amrutanjan-navigation-sprint.md`.

## Goal

The About panel renders Our Story's content cards and History's single thumbnail, each beside the
Subscribe & Save promo, on desktop and in the mobile drawer.

## Requirements

### Functional
- Rail: 2 rows, no icons — Our Story, History
- **Our Story:** pane heading "Our Story"; two `content_card` blocks side by side, each with image, green title, description clamped to 4 lines; full-width "Read More" button below
- **History:** pane heading "History"; one wide rounded image, caption centred beneath, full-width "Check History" button below
- Both panes 684px with the 352px promo at `x:1028`
- Mobile Our Story: cards stack full width, promo drops below the accordion
- Mobile History: same single thumbnail, sized to the drawer

### Non-Functional
- A `content_card` with no image renders text-only, with no broken-image placeholder
- Description clamping must not break mid-word or leave a hanging ellipsis on short copy

## Approach

`content_card` is the **only repeating block type left in the whole header schema** (2.2), so this is
the one place the Sprint §3 ordering rule does real work — cards belong to the `rail_item` that
precedes them. Sprint §5.4 says two in the design, unlimited by convention, so do not cap it.

Sprint §6 notes the designer built these cards on top of the bundle card with price and Add Bundle
layers hidden. That is a Figma artefact. **Build clean** — do not reuse `bundle-card-featured` and
hide parts of it.

Panel heights differ: Our Story 573px, History 668px. That spread is exactly what 2.3's runtime
height measurement exists for; nothing here should hardcode either value.

**History on mobile is unverified against a design.** Render the same thumbnail, caption and CTA
sized to the 360px drawer, and note it in `status-log.md` so 4.3 treats it as a known gap rather
than a fidelity defect.
